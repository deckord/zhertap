# Safe Genplan Export

This tool exports a raster page reviewed in `genplan_workbench` as a WGS84
Cloud Optimized GeoTIFF (COG). If the installed GDAL build has no COG driver, it
creates a tiled, DEFLATE-compressed GeoTIFF instead.

The source must already be a JPG, PNG, TIFF or a PDF page rendered to one of
those formats. The exporter does not render PDFs and never creates, moves or
guesses control points.

The current safe release supports `affine` workbench transforms. A
`projective` submission is blocked instead of silently replacing the reviewed
homography with a different GDAL approximation.

## Release gate

Four input artifacts are required:

1. The source raster.
2. `gcps.json` from `genplan_workbench`, submitted as `qa_pending`.
3. `qa.json` from the same workbench save. Its decision remains `pending`.
4. A separate `review.json` signed off by a different reviewer.

The workbench files remain pending because the workbench is not allowed to
approve its own result. Only the separate review authorizes export. Review
statuses `proposed`, `qa_pending`, `pending`, `REJECT` and `REJECTED` are always
blocked.

`STRICT` permits a normal export. `WARNING` permits only a shadow export and
requires the explicit JSON boolean `allow_shadow: true`.

Every review is bound to the exact source, GCP and QA files by SHA-256. Editing
any of those files after review invalidates the review and blocks export.

Example `review.json`:

```json
{
  "schema_version": "1.0",
  "record_id": "asset-123",
  "source_sha256": "<64 lowercase hex characters>",
  "gcps_sha256": "<64 lowercase hex characters>",
  "qa_sha256": "<64 lowercase hex characters>",
  "status": "STRICT",
  "allow_shadow": false,
  "independent_review": true,
  "reviewer": "reviewer-2",
  "reviewed_at_utc": "2026-07-23T10:30:00+00:00",
  "notes": "Checked against independent checkpoints and reference imagery."
}
```

The reviewer must not equal the GCP operator recorded in `gcps.json`.

## Dependency

Rasterio is intentionally optional and is imported only during export:

```powershell
python -m pip install "rasterio>=1.3,<1.5"
```

No system packages or command-line GIS programs are required by this module.
If Rasterio is absent, the CLI exits with an installation message and does not
create a partial export.

## CLI

Store each exported sheet in its own directory because the default report name
is `provenance.json`.

```powershell
python -m tools.genplan_export `
  --source 'C:\genplan\rendered\page-0001.png' `
  --gcps 'C:\genplan\records\asset-123\gcps.json' `
  --qa 'C:\genplan\records\asset-123\qa.json' `
  --review 'C:\genplan\reviews\asset-123.json' `
  --output 'C:\genplan\published\asset-123\sheet.tif'
```

Options:

- `--provenance PATH` changes the report path.
- `--overwrite` explicitly permits replacing existing output files.
- `--no-cog` creates a tiled GeoTIFF even when the COG driver is available.
- `--max-output-pixels N` lowers or raises the default 250 million source and
  output pixel guard.

The command exits with code `2` when validation or export is blocked.

## Provenance

`provenance.json` records:

- SHA-256 of the source, GCP, QA, review and output files;
- independent reviewer, status and release mode;
- output CRS, bounds, dimensions, transform and format;
- the number of original train and checkpoint GCPs;
- confirmation that checkpoints were not used for warping;
- confirmation that no GCP was generated by the exporter.

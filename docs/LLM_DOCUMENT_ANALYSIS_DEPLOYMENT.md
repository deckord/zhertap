# LLM для анализа аукционных документов: production-решение

Последняя проверка: 2026-08-30.

## Текущая среда

- Сервер: 8 vCPU, 15.6 GiB RAM, swap 4 GiB.
- GPU/NVIDIA не обнаружен.
- Ollama работает на CPU.
- Текущий production model: `qwen2.5:3b` Q4_K_M.
- Установлена, но не включена: `qwen3:8b` Q4_K_M.
- В момент проверки Ollama использовал примерно 10.2 GiB RAM, свободной оперативной памяти было около 2.9 GiB, swap уже использовался.

## GLM-5.3 / GLM-5.3-Flash

GLM-5.3 является актуальной флагманской API-моделью Z.ai. GLM-5.3-Flash поддерживает текст, изображения и файлы, structured output и заявлена для document processing.

Однако GLM-5.3-Flash имеет 320B total / 18B active parameters. На текущем CPU-only сервере с 15.6 GiB RAM её нельзя безопасно использовать как локальную Ollama-модель.

Возможный путь использования GLM:

- внешний Z.ai API;
- только после отдельного решения по стоимости, API key и передаче документов третьей стороне;
- документы аукционов могут содержать персональные/договорные сведения, поэтому отправка вовне не включается по умолчанию.

## Рекомендация сейчас

1. Не переключать production на GLM-5.3 локально: сервер для этого недостаточен.
2. Не включать внешний GLM API без отдельной безопасной интеграции и проверки стоимости/конфиденциальности.
3. Сохранять `qwen2.5:3b` для непрерывной обработки текущей очереди.
4. Провести отдельный controlled benchmark `qwen3:8b` против `qwen2.5:3b` на одинаковых локальных документах:
   - качество извлечения срока аренды, обязательств, платежей, ограничений;
   - page/quote grounding;
   - latency p50/p95;
   - RAM, swap, ошибки/OOM;
   - не менять production model, пока benchmark не пройдёт.

## Критерий переключения

`qwen3:8b` можно рассматривать только если он:

- не вызывает OOM или заметного роста swap;
- сохраняет работу worker без блокировки очередей;
- действительно лучше извлекает подтверждённые факты из русско-/казахскоязычных договоров;
- не ухудшает provenance: источник, страница/цитата и статус должны сохраняться.

LLM остаётся извлекателем кандидатных фактов. Она не принимает юридическое решение и не утверждает, что ограничений нет.

# Карта модулей Auctions v2

Дата: 2026-08-04

## Граница продукта

Zhertap Auctions v2 доводит пользователя до решения перед покупкой: найти лот, собрать источники, документы, историю, карту, аналитику, риски, уведомления и чеклист перехода на официальный портал.

Система не подает заявки, не подписывает ЭЦП, не оплачивает гарантийный взнос, не участвует в торгах и не выполняет юридически значимые действия на E-Qazyna/eGov.

Короткий статус простым языком: [AUCTIONS_V2_STATUS.md](AUCTIONS_V2_STATUS.md).

Подробная карта ручного процесса участника и соответствия системы: [AUCTIONS_V2_OPERATOR_WORKFLOW.md](AUCTIONS_V2_OPERATOR_WORKFLOW.md).

## Приоритет добивания

1. Админ-экран диагностики источников, ошибок, дублей и логов синхронизации, чтобы сразу видеть причину `0 лотов`.
2. Проверить и добить E-Qazyna crawler по реальной выдаче земельных лотов: active/upcoming/archive.
3. Расширить gov.kz: news/activities, автодискавер slug-ов акиматов и отдельный backfill по регионам.
4. ЕГКН/публичная кадастровая карта: добить точные границы, ограничения и свободные участки там, где есть открытые слои.
5. Карта v2: добавить кадастровые полигоны, свободные участки и геослои ограничений.
6. Исторический backfill состоявшихся и несостоявшихся торгов.
7. Telegram v2 как полноценный рабочий интерфейс, не только уведомления.

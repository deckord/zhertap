# E-Qazyna: контракт полного архива и годовой аналитики

## Цель

Zhertap должен хранить максимально полный доступный архив **только земельных** лотов E-Qazyna для истории торгов и аналитики. Счётчик E-Qazyna и число строк Zhertap не считаются одинаковыми без сверки условий фильтра и источника.

## Границы данных

- Источник списка: E-Qazyna, `objectType=Land`.
- Защита Zhertap: карточка дополнительно должна иметь явный признак земли; транспорт и прочие активы исключаются.
- Статусы архива: `SuccessProtocolSigned`, `FailureProtocolSigned`, `NullifyResultProtocolSigned`, `CancelBeforeStart`.
- Текущие статусы (`ApplicationsAccept`, `Pending`, `Running`) хранятся отдельно как текущая витрина, а не используются как завершённые аналоги.

## Возобновляемая загрузка

Каждая задача должна иметь независимый checkpoint:

`год → статус E-Qazyna → страница списка → source_lot_id → detail result`.

Для каждого checkpoint сохраняются:

- количество URL в официальном списке;
- число успешно прочитанных карточек;
- число созданных/обновлённых земельных лотов;
- число не-земельных исключений;
- ошибки карточек с причиной и попытками;
- признак полноты страницы/окна.

Нельзя называть год, статус или весь архив завершённым, если имеются `pending`, `error`, provider rate limit либо не сверены source count и сохранённые unique source_lot_id.

## Правило цен по времени

### Current market

Для текущего лота сначала используются строго сопоставимые результаты за последние 365 дней. Цены 2023 года не входят в оценку рынка 2026 года.

### Historical analytics

Исторические данные показываются отдельными годовыми когортами:

- год торгов;
- регион / район;
- назначение;
- право на участок;
- диапазон площади;
- count, медиана стартовой цены, медиана подтверждённой цены, цена за сотку, доля состоявшихся торгов.

### Запрещено

- смешивать номинальные цены 2023 и 2026 в одной медиане "текущей цены";
- подменять цену объявления подтверждённой ценой сделки;
- использовать старый год как current fair value без явно указанного коэффициента индексации и источника этого коэффициента.

Если текущая когорта мала, UI обязан писать, что текущих аналогов недостаточно, а прошлые годы показаны только как тренд.

## Acceptance checks

1. Лот с `vehicle`/`non_land` не попадает в архивную или текущую земельную аналитику.
2. Каждый год имеет независимый coverage status: complete / partial / blocked.
3. Current-market aggregate имеет `event_date_from` и `event_date_to`.
4. Годовая таблица показывает дату и размер выборки.
5. Общий счётчик не подменяет coverage: число E-Qazyna фиксируется с URL/фильтром/временем проверки.

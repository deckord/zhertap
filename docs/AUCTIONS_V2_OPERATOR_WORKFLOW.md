# Auctions v2: рабочий процесс участника земельных аукционов

Дата проверки: 2026-08-04.

Документ фиксирует не список интеграций, а реальный ручной процесс человека, который ищет землю через аукционы, и то, как Zhertap должен заменить этот ручной мониторинг до момента официальной заявки/покупки.

Короткий статус простым языком: [AUCTIONS_V2_STATUS.md](AUCTIONS_V2_STATUS.md).

## Ручной процесс сейчас

| Этап | Куда человек заходит вручную | Что он там проверяет | Что должно быть в Zhertap |
| --- | --- | --- | --- |
| 1. Найти опубликованный лот | E-Qazyna / Sauda | новые торги, статус приема заявок, дата торгов, стартовая цена, гарантийный взнос, регион, продавец, документы | единая лента лотов, быстрые фильтры, дедлайны, уведомления о новом/измененном лоте |
| 2. Найти ранние объявления | gov.kz и сайты акиматов | извещения, перечни участков, протоколы, вложения, контакты управления земельных отношений | связать объявление акимата с лотом по номеру, кадастру, дате, региону и документам |
| 3. Проверить официальный путь | eGov и E-Qazyna | где подается заявка, какие нужны ЭЦП/NCALayer/реквизиты, когда платить гарантийный взнос | только чеклист и прямые ссылки; Zhertap не подает заявки и не подписывает документы |
| 4. Проверить кадастр | ЕГКН / публичная кадастровая карта | кадастровый номер, границы, площадь, адрес, право/назначение, соседние участки | автоматическая сверка кадастра, контур на карте, статус `verified/not_found/unavailable` |
| 5. Проверить ограничения | ЕГКН-слои, ПДП, генпланы, региональные геопорталы | красные линии, функциональная зона, ПДП, инженерные сети, водоохранные зоны | слои риска вокруг участка, статусы проверки, ручная ссылка там, где автоматизация невозможна |
| 6. Проверить окружение | OSM, спутник, карты | дороги, населенные пункты, вода, электричество, инфраструктура, подъезд | расстояния, инфраструктурный блок, карта и флаги риска |
| 7. Оценить цену | архив E-Qazyna, объявления, похожие участки | цена за сотку, история торгов, ликвидность района, разумный максимум ставки | медианы/средние, цена за сотку, история района, ручные/автоматические аналоги |
| 8. Вести pipeline | таблицы, заметки, календарь, Telegram | избранное, максимальная цена, статус решения, напоминания | pipeline лота, watchlists, web/Telegram уведомления, dossier перед переходом |
| 9. Перейти на официальный портал | E-Qazyna/eGov, банк, ЭЦП | заявка, гарантийный взнос, торги, договор, регистрация права | финальный чеклист и внешняя ссылка; юридически значимые действия только вне Zhertap |

## Что уже сделано

- Закрытый admin-only раздел `/cabinet/auctions-v2` для `+77026669475`.

- V2-лента, фильтры, detail-карточка, dossier, pipeline, watchlists, web и Telegram уведомления.
- Счетчики источников, source strip, crawl runs и запуск полной синхронизации v2.
- Gov.kz partial live: `documents/events/seed detail URL`, evidence `akimat_announcement`, вложения в документы.
- ЕГКН partial live: поиск кадастра в WFS `egkn:u_view`, сохранение границы участка, координат, статуса и evidence.
- Карта v2: маркеры, risk/score/deadline, границы ЕГКН, контекстные слои `freelands_view`, `pdp_u_view`, `funczones_view`, `eng_view`.
- OSM-инфраструктура для предварительной оценки окружения.
- Исправлено: каталоги регионов/районов/населенных пунктов для аукционов больше не зависят только от найденных лотов E-Qazyna. Каркас берется из ЕГКН, поверх него показываются счетчики аукционных лотов.
- Исправлено: поиск по кадастровому номеру работает с разными форматами номера, включая ввод без разделителей.
- Добавлен блок "Решение перед участием": простое резюме, что проверено, что мешает решению, личный максимум ставки, заметка и рабочий статус.
- Документы в карточке показывают не только ссылку, но и состояние: файл только найден, скачан локально или была ошибка скачивания.

## Что еще не добито

- Реальная полнота данных E-Qazyna: если на экране 0 лотов, нужно видеть, это ошибка интеграции, пустой ответ источника, слишком узкий фильтр или отсутствие активных торгов.
- Отдельные разделы по рабочему процессу: новые лоты, будущие, свободные/подготовленные участки, история, районы, аналитика.
- Массовый поиск свободных и подготовленных к аукциону участков через ЕГКН/геопорталы, а не только анализ уже найденных лотов.
- Полный gov.kz/aкиматы: news/activities, автодискавер региональных slug-ов, backfill объявлений и протоколов.
- Исторический backfill состоявшихся/несостоявшихся торгов для нормальной рыночной статистики.
- Автоматические рыночные аналоги и медианы по району/назначению/площади.
- Региональные геопорталы: Шымкент, Астана, Алматы/Алматинская область и остальные области как реестр live/manual источников.
- Telegram bot v2 как полноценный рабочий интерфейс: поиск, фильтры, карточка, документы, история, статистика.

## Следующий порядок разработки

1. Данные и диагностика: добиться, чтобы админ сразу видел причину `0 лотов` и мог перезапустить/проверить каждый источник.
2. Справочники и подписки без лотов: область, район, населенный пункт, категория, бюджет и площадь должны сохраняться даже до появления первого лота.
3. Источник E-Qazyna: проверить текущий crawler на реальной выдаче земельных лотов, статусах и фильтрах, отдельно active/upcoming/archive.
4. Источник акиматов: расширить gov.kz и сделать региональный реестр сайтов/страниц.
5. ЕГКН/геопорталы: вывести свободные и подготовленные участки отдельным слоем и отдельной таблицей.
6. Аналитика: собрать историю торгов и рыночные сравнения, чтобы пользователь видел разумный потолок ставки.
7. UX рабочего процесса: экран должен вести человека по шагам `найти -> проверить -> оценить -> следить -> перейти`, а не просто показывать технические статусы интеграций.

## Контрольная формула готовности

Модуль считается полезным не тогда, когда подключен очередной API, а когда пользователь может открыть один лот и ответить:

- где официальный лот и документы;
- какой кадастр и границы;
- что вокруг участка;
- какие ограничения уже проверены, а что надо проверить вручную;
- сколько стоит сотка и дорого ли это для района;
- сколько времени осталось;
- какой максимальный бюджет;
- стоит участвовать или нет;
- куда перейти для официальной заявки.

## Что означает оставшийся технический backlog

Все бывшие `336` QA/shadow-строк получили итоговое решение:

- `21` слой (`7` комплектов) переведён в `VERIFIED_STRICT/search`;
- `99` слоёв (`33` комплекта) получили `SUPERSEDED`: `25` комплектов уже
  имели действующий строгий релиз, `8` были повторными shadow-выгрузками;
- `216` слоёв (`72` комплекта) получили `REVIEWED_HOLD`: для `65` комплектов
  официальный документ есть в АИС ГГК, но не найдена допустимая публикация
  правового акта на Adilet/gov.kz; ещё `7` региональных выгрузок не имеют
  достаточно строгого соответствия функциональных зон.

Отдельно остаётся каталог будущих исходных материалов, не являющийся очередью
этих 336 слоёв:

- `142` исходных документа со статусом `legend_draft_ready`;
- `1 313` распознанных элементов легенды со статусом `needs_review`;
- `344` записи каталога источников со статусом `not_imported`.

Это **не остаток ручной проверки 641 точек** и не признак того, что оператор
что-то пропустил. Это каталог возможных будущих источников и черновиков для
расширения автоматического покрытия. Они не должны включаться простым
изменением флагов в БД. Для каждого нового набора необходим отдельный
воспроизводимый релиз, проверка источника и независимый QA.

## Что считается завершенным

- Все сформированные операторские точки вручную классифицированы.
- Текущие 111 утвержденных слоев используются поиском.
- Астана из документа АИС ГГК 3607 активна в боевой БД.
- Клиентская и административная карты генплана открывают подключенные слои и
  рассчитанные точки.
- Для территории без утвержденного слоя система не создает ложную уверенность:
  поиск продолжается как предварительный, а отчет явно требует ручной сверки.

## Что не считается завершенным

- Нет 100% автоматического покрытия каждого населенного пункта Казахстана.
- Необработанных `WARNING` среди прежних 336 слоёв нет; `REVIEWED_HOLD` не
  является боевым статусом и не участвует в поиске.
- Ручная классификация точки по спутнику не подтверждает юридическую свободу,
  право предоставления участка или актуальность всех ограничений.
- Новые официальные документы в будущем потребуют новых релизов и QA, даже
  если текущая ручная очередь равна нулю.

## Что конкретно осталось

Остаток не требует от пользователя дополнительной разметки в веб-интерфейсе:

1. Следить за публикацией допустимых правовых актов для `65` комплектов в
   `REVIEWED_HOLD`. После появления официальной публикации комплект проходит
   повторный строгий QA и может быть включён отдельным релизом.
2. Подготовить более строгую привязку функциональных зон для `7` региональных
   комплектов в `REVIEWED_HOLD`.
3. Подключать новые населённые пункты по мере появления официальных
   геопривязанных источников. Текущий каталог будущего расширения содержит
   `344` источника `not_imported`, `142` исходных документа
   `legend_draft_ready` и `1 313` элементов легенд `needs_review`.
4. В отдельной технической задаче унифицировать исторические варианты названий
   областей (`Жетісу/Жетысуская`, `Ұлытау/Улытауская`). Это не меняет геометрию
   и не возвращает обработанные 336 слоёв в очередь.

Пункты выше являются планом расширения продукта. Они не означают, что в
текущей партии остались неотмеченные точки или необработанные слои.

## Контрольные production-запросы

Ручная очередь:

```sql
select status, count(*)
from planning_candidate_reviews
group by status
order by status;
```

Активные слои:

```sql
select active, approved_for_search, qa_status, count(*)
from urban_plan_layers
group by active, approved_for_search, qa_status
order by active desc, approved_for_search desc, qa_status;
```

Количество активных областей применения:

```sql
select count(distinct (region, district, locality, purpose))
from urban_plan_layers
where active and approved_for_search;
```

Астана:

```sql
select region, purpose, layer_kind, source_version, qa_status, active
from urban_plan_layers
where active
  and approved_for_search
  and lower(region) like '%астан%'
order by purpose, layer_kind;
```

## Правило для следующих релизов

Ручная очередь точек и конвейер источников должны всегда отражаться отдельно.
Фраза «генпланы не закончены» без уточнения запрещена: нужно явно говорить
либо о новых территориях без опубликованного правового подтверждения, либо о
PDF/легенда-конвейере, либо о ручных точках. Ручные точки и прежние 336
цифровых слоёв разобраны полностью; дальнейшая работа — появление новых
официальных публикаций и новых источников, а не пропущенная операторская
проверка.

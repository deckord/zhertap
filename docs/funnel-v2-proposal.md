# Land Scout Kazakhstan: предложение новой клиентской воронки V2

Статус: проект для согласования. Код, сообщения и кнопки бота пока не изменяются.

## 1. Что остается без изменений

- алгоритмы поиска и ранжирования;
- ЕГКН, OSM, генплан/ПДП и остальные источники;
- расчет площади и геометрии;
- первые 3 участка бесплатно;
- стоимость активации 1 490 ₸;
- бессрочный доступ после одной подтвержденной оплаты для Telegram user ID;
- до 10 результатов в одном пакете;
- исключение ранее отправленных координат;
- ApiPay/Kaspi, webhook и автоматическая доставка после оплаты;
- полный текст `/terms`, `/privacy`, `/offer`;
- юридические предупреждения и необходимость проверки в акимате.

## 2. Что меняется

- пользователь сначала видит результат и пользу, затем объяснение и ограничения;
- технические термины заменяются простыми объяснениями;
- выбор ЛПХ разделяется на короткие последовательные вопросы;
- длинные сообщения разбиваются на короткие блоки;
- появляется понятный индикатор поиска;
- перед отчетом появляется отдельное сообщение о количестве результатов;
- бесплатная выдача и предложение оплаты получают отдельные сообщения;
- после ApiPay `paid` появляется подтверждение оплаты до отправки отчета;
- кнопки формулируются как следующее полезное действие;
- тексты ошибок объясняют, что делать дальше;
- русская и казахская версии проходят отдельную языковую проверку.

## 3. Формулировки, которые нельзя использовать буквально

### «Это реальные участки»

Нельзя обещать, что найденные места являются официально свободными участками.

Безопасный вариант:

```text
Это результаты расчетного поиска по доступным публичным данным.
```

### «Только государственные источники»

ЕГКН является публичным государственным кадастровым источником, но
OpenStreetMap не является государственным источником.

Безопасный вариант:

```text
Для анализа используются публичные кадастровые и картографические данные.
```

### «Официальная регистрация ИП»

Показывать только после заполнения и проверки:

```text
SERVICE_PROVIDER_NAME
SERVICE_PROVIDER_STATUS
SERVICE_PROVIDER_ID
SERVICE_PROVIDER_ADDRESS
SERVICE_PROVIDER_CONTACT
```

До этого строка в доверительном блоке не выводится.

## 4. Пошаговый переход без риска

### Этап 1. Утверждение текстов

1. Утвердить русскую мастер-версию.
2. Проверить обещания и юридические предупреждения.
3. Перевести утвержденную версию на казахский.
4. Провести отдельную проверку казахского носителем языка.

### Этап 2. Техническая подготовка

1. Вынести клиентские тексты в единый каталог `funnel_v2`.
2. Не менять функции поиска, платежей и доставки.
3. Добавить настройку `CLIENT_FUNNEL_VERSION=v1|v2`.
4. Оставить возможность мгновенно вернуть V1.
5. Добавить снимочные тесты всех сообщений RU/KZ.

### Этап 3. Индикатор поиска

Индикатор должен отражать реальные этапы. Нельзя показывать зеленую галочку,
если проверка фактически не закончилась.

Допустимые состояния:

```text
⏳ Сопоставляю границы зарегистрированных участков...
⏳ Проверяю дороги и отмеченные объекты...
⏳ Сверяю ограничения застройки, если доступна цифровая карта...
⏳ Проверяю, помещается ли выбранная площадь...
⏳ Отбираю лучшие варианты...
```

Для этого добавляются только события прогресса. Алгоритм и решение о пригодности
не меняются.

### Этап 4. Аналитика

Добавить события:

```text
start_opened
language_selected
terms_accepted
purpose_selected
lph_mode_selected
region_selected
district_selected
locality_selected
search_confirmed
search_completed
free_results_delivered
paywall_viewed
payment_button_clicked
invoice_created
payment_paid
report_delivered
next_batch_clicked
```

### Этап 5. Запуск

1. Включить V2 только для администратора.
2. Пройти все ветки RU/KZ.
3. Проверить бесплатный лимит, оплату, ошибки, отсутствие генплана и повторный пакет.
4. Включить V2 для 20% новых пользователей.
5. Сравнить конверсии V1/V2 минимум 7 дней.
6. После проверки включить V2 всем.

## 5. Полная структура V2

Основной путь:

```text
/start
→ язык
→ приветствие и согласие
→ назначение
→ параметры ЛПХ при необходимости
→ область
→ район или вся область
→ населенный пункт или территория района
→ подтверждение
→ поиск и прогресс
→ результат
→ первые 3 бесплатно
→ предложение полного доступа
→ ApiPay/Kaspi
→ подтверждение оплаты
→ полный отчет
→ следующие 10 или новая территория
```

Сохраняемые развилки:

```text
нет результатов
техническая ошибка
нет цифрового генплана
результат заблокирован генпланом
истекла QR-ссылка
уже существует ожидающий счет
доступ уже оплачен
следующих новых вариантов нет
справочник ЕГКН временно недоступен
бот открыт в группе
```

## 6. Юридические документы

Тексты `/terms`, `/privacy`, `/offer` не переписываются в рамках маркетинговой
воронки. Меняются только ссылки, расположение и короткие вводные подписи.

Согласие остается явным:

```text
Начать поиск и принять условия
Іздеуді бастау және шарттарды қабылдау
```

В заявке по-прежнему сохраняются:

- версия условий;
- точный снимок полного текста;
- дата и время согласия;
- Telegram user ID.

## 7. Критерии приемки будущей реализации

1. Все текущие функции доступны в V2.
2. Поиск и число кандидатов совпадают с V1 при одинаковых параметрах.
3. Бесплатно суммарно отправляется не более 3 участков на Telegram user ID.
4. Цена везде равна 1 490 ₸.
5. После одной оплаты новые поиски не требуют повторной оплаты.
6. Номер карты не показывается при включенном ApiPay.
7. Существующий счет повторно отправляется без создания второго.
8. После `paid` сначала приходит подтверждение, затем отчет.
9. При отсутствии генплана сохраняется отдельное явное согласие.
10. При нулевом результате и ошибке оплата не запрашивается.
11. Все ошибки имеют повтор, выбор населенного пункта, района и области.
12. Казахский пользователь не получает русский клиентский текст.
13. Кнопки группы ведут только в личный чат.
14. `/terms`, `/privacy`, `/offer`, `/status`, `/whoami` продолжают работать.
15. Старую V1 можно вернуть одной настройкой без восстановления базы.

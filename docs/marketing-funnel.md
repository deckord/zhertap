# Land Scout Kazakhstan: клиентская воронка

Актуально для версии бота от 27.07.2026. Значения в фигурных скобках формируются
динамически. Текущая модель: единый сервис с двумя разделами — поиск возможных
мест под ЛПХ/садоводство и земельные аукционы E-Qazyna. Бесплатно доступны первые
3 участка в поиске земли и 1 полный аукционный лот. Затем предлагается однократная
активация единого бессрочного доступа за 4 990 ₸; после подтверждения оплаты
дальнейшие поиски и аукционы для этого Telegram user ID доступны без дополнительной
оплаты.

## 1. Карта воронки

| Этап | Действие клиента | Результат | Основное событие |
|---|---|---|---|
| 1 | Открывает бота и нажимает `/start` | Выбор языка | `start_opened` |
| 2 | Выбирает `Русский` или `Қазақша` | Приветствие и условия | `language_selected` |
| 3 | Нажимает согласие | Главное меню с двумя разделами | `terms_accepted` |
| 4А | Выбирает поиск места под участок | Выбор ЛПХ или садоводства | `purpose_selected` |
| 4Б | Выбирает земельные аукционы | Фильтры E-Qazyna | `auction_opened` |
| 5А | Выбирает область, район и населенный пункт | Выбор территории поиска | `location_selected` |
| 5Б | Выбирает регион, назначение, цену и площадь лота | Подбор лотов | `auction_filter_completed` |
| 6А | Проверяет параметры и отправляет заявку | Заявка попадает в очередь | `search_submitted` |
| 6Б | Открывает результат аукционного поиска | Получает 1 полный лот бесплатно или paywall | `auction_results_viewed` |
| 7 | Ожидает поиск участка | ЕГКН, OSM и доступный генплан/ПДП | `search_completed` |
| 8А | Получает до 3 первых участков | Бесплатная демонстрация ценности | `free_preview_delivered` |
| 8Б | Получает сообщение об отсутствии результата | Повтор или смена территории | `zero_result` |
| 8В | Генплан отсутствует | Согласие на результат без генплана | `genplan_override_viewed` |
| 9 | Бесплатный лимит исчерпан | Предложение единой активации за 4 990 ₸ | `paywall_viewed` |
| 10 | Нажимает оплату | Получает персональную Kaspi/ApiPay-ссылку | `invoice_created` |
| 11 | Оплачивает | ApiPay подтверждает платеж | `payment_paid` |
| 12 | Получает полный отчет или полный доступ к лотам | Доступ активирован бессрочно для Telegram user ID | `report_delivered` |
| 13 | Нажимает следующие 10, выбирает другую территорию или возвращается к аукционам | Повторное использование | `repeat_search_started` |

## 4. Выбор территории

Последовательность экранов:

1. `Загружаю справочник областей ЕГКН...` → `Выберите область:`
2. `Загружаю районы ЕГКН...` → `Область: {область}\nВыберите район:`
3. Кнопка `🔎 Все районы · по 1 участку` либо конкретный район.
4. `Загружаю населенные пункты ЕГКН...`
5. `Район: {район}\nВыберите населенный пункт:`
6. Если населенных пунктов нет, поиск автоматически идет по территории района.
7. `Населенный пункт: {пункт}\nНазначение: {назначение}\nПлощадь поиска: {N} соток`.

Казахская версия использует те же этапы: `Облысты таңдаңыз`, `Ауданды таңдаңыз`,
`Елді мекенді таңдаңыз`, `Барлық аудандар · әр ауданнан 1 учаске`.

На каждом уровне доступны кнопки возврата к назначению, области, району,
населенному пункту или в главное меню выбора областей.

## 6. Развилки поиска

### 6.1. Ничего не найдено

```text
Поиск завершен. Найдено: 0 из 10.
{причина}

Система ищет до 10 вариантов и не требует найти ровно 10. В этом населенном
пункте не найдено ни одного подходящего промежутка.

Оплата не запрашивается.
```

Кнопки: `Повторить поиск`, `Выбрать город/село`, `Выбрать район`,
`Выбрать область`.

### 6.2. Техническая ошибка

```text
Поиск не удалось завершить после повторных попыток. Публичный сервис ЕГКН
или сервис проверки дорог и объектов OSM мог временно не ответить, либо
обработка населенного пункта заняла слишком много времени.

Результат не сформирован, оплата не запрашивается. Запустите повторный поиск
кнопкой ниже.
Номер заявки: {UUID}
Статус: /status {UUID}
```

Кнопки: повтор, населенный пункт, район, область. Казахская версия полностью
переведена.

### 6.3. Нет пригодного слоя генплана/ПДП

```text
Для выбранного населенного пункта нет пригодного официального
геопривязанного слоя генплана/ПДП. При желании можно запросить
предварительный результат только по ЕГКН и OSM.

Официальный геопривязанный слой генплана/ПДП для выбранного населенного
пункта отсутствует. Я прошу продолжить предварительный поиск только по
публичному слою ЕГКН и открытым данным OSM и понимаю, что результат не
проверен по генплану, ПДП, красным линиям и может не соответствовать
градостроительным ограничениям.
```

Главная кнопка: `Получить предварительно без генплана`.

После нажатия: `Предварительный результат обработан без проверки генплана.`

### 6.4. Кандидаты не прошли генплан

```text
ЕГКН показал расчетные промежутки, но ни один из них не прошел проверку
по загруженному официальному генплану/ПДП. Координаты не выдаются,
оплата не запрашивается.
```

## 7. Бесплатные 3 участка

Если бесплатный остаток больше нуля, бот автоматически отправляет отчет
с заголовком `🎁 БЕСПЛАТНЫЕ ТЕСТОВЫЕ УЧАСТКИ` / `🎁 ТЕГІН СЫНАҚ УЧАСКЕЛЕРІ`.

Для каждого участка показываются:

- район и координаты;
- соседний кадастровый номер и расстояние до него;
- назначение соседнего участка;
- разрешенная зона генплана/ПДП либо отметка об отсутствии проверки;
- расстояние до кладбища по открытым данным;
- краткое пояснение проверки;
- ссылка на карту;
- готовая формулировка для обращения;
- предупреждение, что это расчетное место, а не официальный свободный участок.

Если найдено больше бесплатного остатка, сразу после бесплатной части
показывается платное предложение.

## 10. Оплата и полный отчет

После статуса `paid` ApiPay автоматически активирует доступ и бот сразу
отправляет полный отчет. Отдельного сообщения `Оплата успешно принята`
сейчас нет: подтверждением для клиента служит появление полного отчета.

Заголовок полного отчета: `🗺 ИНФОРМАЦИОННЫЙ ОТЧЕТ` /
`🗺 АҚПАРАТТЫҚ ЕСЕП`. Состав полей совпадает с бесплатным отчетом, но
включает все найденные варианты пакета, максимум 10.

После отчета:

```text
Можно найти следующие 10 новых участков или выбрать другую территорию.
Уже отправленные варианты повторяться не будут.
```

Кнопки: `Следующие 10 участков`, `Выбрать город/село`, `Выбрать район`,
`Выбрать область`. Для нового пакета оплата повторно не требуется.

## 11. Юридические страницы

Команды `/terms`, `/privacy`, `/offer` не являются обязательными отдельными
экранами воронки: ссылки на них присутствуют в приветствии и отчетах.

- `/terms`: независимый статус сервиса, предмет анализа, бесплатный лимит,
  цена и бессрочный доступ, отсутствие гарантии выдачи земли, ограничения
  ЕГКН/OSM/генплана, проверка акиматом и порядок возврата.
- `/privacy`: Telegram ID/chat ID, параметры заявок, результаты, платежный
  статус, срок и место хранения, права пользователя.
- `/offer`: предмет услуги, порядок формирования результата, цена,
  автоматическая оплата, доставка и обращения.

Согласие сохраняется в заявке как версия правил, время и точный снимок полного
текста `/terms`.

## 12. Что уже можно измерить

Из таблиц заявок можно посчитать:

- количество созданных поисков и уникальных Telegram user ID;
- язык, назначение и выбранную географию;
- долю успешных, пустых и технически неуспешных поисков;
- число найденных и бесплатно отправленных участков;
- показы платного предложения косвенно через исчерпанный бесплатный лимит;
- созданные счета, ожидающие, оплаченные, отмененные и истекшие платежи;
- конверсию `счет → оплата`;
- доставку полного отчета и запуск следующих пакетов;
- повторные поиски и удержание оплативших пользователей.

Сейчас нельзя надежно измерить:

- открытие `/start` без создания заявки;
- отказы на выборе языка, условий, назначения и территории;
- фактическое нажатие URL-кнопки Kaspi;
- просмотр отдельных частей длинного отчета.

Для полной продуктовой аналитики нужны отдельные события на каждом callback и
платежная ссылка через собственный редирект. Рекомендуемые основные конверсии:

1. `/start → согласие`;
2. `согласие → созданная заявка`;
3. `заявка → найден хотя бы один участок`;
4. `бесплатный отчет → платное предложение`;
5. `платное предложение → создан счет`;
6. `создан счет → paid`;
7. `paid → полный отчет доставлен`;
8. `полный отчет → следующий поиск в течение 7/30 дней`.
